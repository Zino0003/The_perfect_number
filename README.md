# 🔢 فاحص الأعداد التامة (Perfect Number)

سكريبت بسيط بلغة بايثون يحدد ما إذا كان العدد الصحيح المدخل **عدداً تاماً** أم لا.

---

## 📌 المميزات
* استقبال عدد صحيح من المستخدم.
* حساب مجموع قواسم العدد.
* طباعة ما إذا كان العدد **تاماً (Parfait)** أم **غير تام**.

---

## 🚀 طريقة التشغيل
python "nombre parfait.py"
